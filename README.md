# massmodel-cosi-em
Mass model for Engineering Model cryostat based on the CAD model

03/19/2026: This model contains:
1. Cryostat box
2. PIP deck
3. ACS: Inactive walls except for one active BGO side shield on the negative X side (closest to the active detector)
4. One test detector holder at Q1L0
5. One test inactive detector at Q1L0
6. A test detector stack holed (made up of the U-frame and skirts)
